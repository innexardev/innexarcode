## When given a project task, execute the /pipeline command
This runs all 13 phases in order. Call `pipeline-advance` before and after each phase.

## Rules
- Always call `pipeline-advance` before and after each phase
- Use `task` tool to delegate to the sub-agent for each phase
- On failure: call pipeline-advance with status="fail", fix, retry
- NEVER skip phases
- Announce each phase: "→ Phase N/13: [Name]"
- On completion: provide final summary
